# Internship_thesis
Repository for internship thesis.
We used **"Plot_PCA_Modified_Original.R"** script to generate the PCA plot and the legend present in figure 10 and 11 for example. 
To run **"Plot_PCA_Modified_Original.R"** you need to generate tsv file as input file , have an eingenval file related to your tsv file, evec number must be equal to collumn number of tsv file with the corresponding PC scores. Also worth noting that the file cannot have any especial symbols plain writting without spaces should minimize errors.
In figure 18 and 20 in thesis for example we still used **"Plot_PCA_Modified_Original.R"** but altered the Excel file by changing the colors of the non target populations to **"darkgrey"** and maintained the colors of the populations we wanted to show.
We used **"Bar_Plot_Percentages.py"** to generate the image of figure 17 in thesis input file should be in **".txt"** format and output file should be in **".png"** format.
